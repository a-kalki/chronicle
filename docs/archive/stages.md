# Завершённые этапы

Краткие итоги закрытых этапов [плана](../plan.md). Чек-листы и подробности — в истории git (`git log --oneline <диапазон>`).

## Этап 1. Ядро и локальный сервис — 2026-10-17 (`efb9fb6`…`6c7725d`)
Каркас на Bun + Biome, контракт v1 (valibot → JSON Schema), домен (нормализация remote, активное время, схожесть), SQLite с миграциями, приём отчёта с идемпотентностью по `(agent, sessionId, seq)`, поиск и учёт пользы знаний, HTTP API `/v1` с bearer-токеном, CLI `chronicle` с outbox.

## Этап 2. Курирование знаний — 2026-10-17 (`7cd69e2`, `bceb6b8`)
OpenAI-совместимый LLM-клиент, курирование кандидатов (`create` / `merge` / `discard`) с историей, фоновый курьер, архивирование неиспользуемых записей, промпт выжимки «только ловушки и факты». Пересборка курированной базы отложена до реальной потребности.

## Этап 3. Адаптеры — 2026-10-17 (`578ada7`…`f2d2361`)
Общий `chronicle finish` (watermark, фон, режим хука), адаптеры Claude Code (хук `SessionEnd`) и pi (пакет `integrations/pi`), скил recall. agy не подключён — перенесён в «Потом».

## Этап 4. Миграция и деплой — 2026-10-17 (`c2d3f47`…`763acc7`)
Деплой на kalki-server ([deploy.md](../deploy.md)), один сервис для ноутбука и сервера, импорт из pi-chronicle ([pi-chronicle-migration.md](pi-chronicle-migration.md)), подключение Claude Code и pi. Доводка по живым сессиям: продолжение сессии без повторов, брошенные ветки pi `/tree`, SSH-алиасы в remote (`f19cdae`…`d585abc`).

## Этап 5. MCP — 2026-10-17 (`bed5d6c`…`42cfa7f`)
`/mcp` (Streamable HTTP) только для чтения и учёта пользы: `knowledge_search`, `knowledge_get`, `knowledge_used`. Попутно: проект по remote с SSH-алиасом клиента, найденная и подошедшая ловушка не присылается заново, результат фонового итога в строке статуса и уведомлении pi.

## Этап 6. Модель работы v2 — 2026-10-18 (`dc8b591`…`323982e`)
Проект — у хода (по весам путей инструментов, игнорируемые своим репо пути не в счёт), коммиты из всех затронутых репо, эпизоды и фокусы от выжимки, люди по токенам (`CHRONICLE_TOKENS=человек:токен`). Контракт v2 (v1 принимается), миграция без конвертации, `chronicle replay`, `GET /v1/facts`, `chronicle report day`. Проверено на проде: 17.10 — chronicle 2.5 ч / 28 коммитов и u7-school 4.0 ч / 9 коммитов раздельно (совпадает с git), параллельное время 0.2 ч.

## Этап 7. Адаптер agy — 2026-10-18 (`6cdc589`…`1e2770c`)
Чтение transcript.jsonl (активность, ходы из USER_EXPLICIT, действия edit/read/shell из tool_calls, cwd из conversation_summaries.db / Cwd), неинтерактивная выжимка через `agy -p` со схемой (gemini-3.8-flash-low), регистрация в адаптерах chronicle. Скилы /finish и recall, проверено на живой сессии.
