# finish — итог сессии в chronicle

Запускает фоновый процесс выжимки и сборки отчёта сессии для chronicle.

## Порядок действий

1. Получи ID текущей сессии:
   - Из переменной окружения `$ANTIGRAVITY_CONVERSATION_ID`, либо
   - Из контекста разговора (Conversation ID).
2. Запусти команду в фоне через `--detach`:
   ```bash
   chronicle finish --agent agy --session <session_id> --detach
   ```
3. Сразу сообщи пользователю:
   «Итог сессии формируется в фоне. Отчёт уходит в chronicle.»
