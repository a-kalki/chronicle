# chronicle

Сервис, который собирает итоги рабочих сессий с агентами (Claude Code, pi, agy) на любых машинах и отвечает на два вопроса о работе человека:

1. **Что сделано** — вклад для команды, результат для заказчика.
2. **Сколько работал** — вовлечённость для команды, основание оплаты для заказчика.

За что отвечает:
- **хранит факты**, а не готовые отчёты: активность, ходы (реплика человека и работа агента до следующей реплики), результаты, коммиты. Эпизоды, время и метрики вычисляются из фактов при чтении, поэтому отчётность можно строить потом, здесь или во внешнем сервисе;
- **привязывает работу к проекту, где она шла**, а не к каталогу запуска агента: проект определяется у каждого хода, коммиты собираются из всех затронутых репозиториев;
- **считает время без двойного счёта**: параллельные сессии не дают лишних часов, параллельное время показывается отдельно — `5.6 ч (паралл. 1.1 ч)`;
- **ведёт базу знаний**: ловушки и неочевидные факты окружения, курирование на стороне сервиса, учёт пользы.

Вспомогательные метрики (организованность, переключения, работа с агентами) — производные от тех же фактов, см. спецификацию §4.

```bash
bun install
bun run check   # lint + typecheck + тесты

# сервис (настройки — chronicle.server.json, токены можно через CHRONICLE_TOKENS)
CHRONICLE_TOKENS=<токен> bun src/http/main.ts

# клиент (~/.config/chronicle/config.json: serverUrl, token, host)
bun src/cli/main.ts help
```
