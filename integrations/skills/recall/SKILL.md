# recall — база ловушек chronicle

База хранит ловушки (симптом → причина → решение) и неочевидные факты окружения, накопленные всеми агентами на всех машинах. Ищет в текущем проекте (по git remote) и в общих записях.

## Когда

- Неожиданная ошибка: сборка, runtime, тесты, линтер, git, ssh, деплой.
- Инструмент ведёт себя странно: флаг не работает, конфиг игнорируется, тихий сбой.

Не нужен перед обычной задачей — только при ошибке или странности.

## Как

```bash
# Дословный текст ошибки — главный ключ; лучшие совпадения первыми
chronicle search "bash: line 1: bun: command not found"

# Запись целиком
chronicle show <id>
```

Нашлась подходящая запись — примени решение. Помогла она или нет, учтётся в итоге сессии автоматически; отдельно отмечать не нужно.

Ничего не нашлось — чини сам. Итог сессии (в том числе новая ловушка) уйдёт в chronicle при её завершении.
